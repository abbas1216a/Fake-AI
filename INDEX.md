## 🔌 Integration Options

### 🌐 Browser-Based (TensorFlow.js)
```javascript
// No server needed
async function analyzeWithML(input) {
  const model = await tf.loadGraphModel('model.json');
  return model.predict(input);
}
```

### 🖥️ Backend API
```javascript
// Python/Node.js server
async function analyzeViaAPI(input) {
  const response = await fetch('/api/analyze', {
    method: 'POST',
    body: JSON.stringify(input)
  });
  return response.json();
}
```

### 🔀 Hybrid
```javascript
// Browser + Backend
const mlScore = await analyzeWithML(input);     // Fast
const apiScore = await analyzeViaAPI(input);    // Accurate
const combined = (mlScore + apiScore) / 2;      // Best of both
```

## 🆘 Troubleshooting

### App won't load
- Check browser console (F12)
- Ensure all files in same directory
- Try different browser
- Clear cache

### Scores seem random
- That's the demo! Replace with ML models
- Scores use seeded randomness for demo
- See [ML_INTEGRATION_GUIDE.md](./ML_INTEGRATION_GUIDE.md)

### Results always high/low
- Adjust scoring weights in `app.js`
- Review [TESTING_GUIDE.md](./TESTING_GUIDE.md) calibration
- Test with known samples
